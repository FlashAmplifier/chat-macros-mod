## 📖 About

Chat Macros binds complex chat commands, multi-line messages, or command sequences to single hotkeys for fast server interaction and farm control.

---

## ✨ Features
<a name="features"></a>

- **Unlimited Macros** — bind any text or `/command` to a key.
- **Sequences** — chain multiple commands with configurable delays.
- **Variable Support** — insert XYZ, player name, or time into messages.
- **GUI Editor** — drag-and-drop macro manager.
- **Import/Export** — share macro sets as JSON files.
- **Toggle Key** — lock all macros to prevent accidental triggers.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
